# Pi OS
Bare-bones operating system for the raspberry pi. 

### About
* Cross-compiled and linked a 64-bit kernel in C using LLVM/Clang to target the ARM microprocessor of a Raspberry Pi 3. 
* Bootstrapped the processor with ARM Assembly, then wrote a linker script to combine the assembly program and kernel.

This was very much a learning opportunity for me to understand how things worked at a low-level with an operating system and doesn't have much real-world use. Either way, it was a lot of fun building!
